## 關於這個專案

一個完整的產品銷售頁範例，使用純 HTML + CSS + JavaScript 打造，沒有任何框架。

主題是「魔術師聲音訓練」，但結構可以套用到任何產品或服務。

---

## 頁面結構

總共 11 個區塊，這是經典的 Landing Page 架構：

1. **Hero** - 主視覺，一句話抓住注意力
2. **Pain Points** - 戳中痛點，讓人產生共鳴
3. **Solution** - 提出解決方案（M.A.G.I.C. 系統）
4. **About** - 建立信任感，介紹自己
5. **Services** - 價格方案比較
6. **Testimonials** - 社會證明，別人怎麼說
7. **Free Offer** - 降低門檻，先體驗再決定
8. **FAQ** - 打消疑慮
9. **Limited Offer** - 製造緊迫感
10. **Final CTA** - 最後一推
11. **Footer** - 聯絡資訊

---

## 互動功能

- 見證輪播（5 秒自動切換）
- FAQ 手風琴展開收合
- 倒數計時器
- 浮動 CTA 按鈕（滾動後出現）
- Modal 彈窗表單
- 表單驗證

## 隨想

### Landing Page 的汙名

說起來有點感慨。

這幾年因為詐騙氾濫，Landing Page 這個詞在很多人心中已經跟「詐騙」劃上等號了。看到一頁式網站，第一反應就是「這是不是詐騙？」

但 Landing Page 本來不是這樣的。

它只是一種專注於單一目標的網頁設計方式——讓訪客採取一個行動。可以是訂閱電子報、預約諮詢、購買產品。這個概念本身沒有對錯，就像刀子可以切菜也可以傷人。

### 成長駭客的興衰

不知道還有多少人記得「成長駭客」（Growth Hacking）這個詞？

大概 2015-2018 年那陣子，這個概念風靡一時。A/B Testing、轉換率優化、漏斗分析、病毒式傳播⋯⋯每個新創都在講這些。Landing Page 就是成長駭客工具箱裡的核心武器之一。

那時候做 Landing Page 是一件很酷的事，代表你懂得用數據驅動成長，懂得優化每一個轉換環節。

現在呢？成長駭客這個詞幾乎沒人提了，Landing Page 則被詐騙集團玩壞了。

時代變化真快，令人不勝唏噓。
